# 🚀 Projeto Alura

Projeto desenvolvido durante os estudos de **HTML e CSS**, com foco na criação e estilização de uma página web.

## 📂 Estrutura do projeto

### 💻 Arquivos principais

* [📄 index.html](./index.html) — Arquivo principal do projeto. Contém a estrutura e os elementos da página utilizando HTML.
* [🎨 style.css](./style.css) — Arquivo responsável pela estilização da página, incluindo cores, tamanhos, posicionamento, fontes e layout.
